# 论文核心研究问题与贡献点分析

## 当前问题分析

根据审稿人意见，当前的技术报告存在以下问题：
1. **缺乏明确的核心研究问题** - 将整个系统作为创新点，缺乏聚焦
2. **缺乏严谨的实验设计** - 没有与SOTA方法的对比实验
3. **缺乏公共数据集验证** - 仅在私有数据上测试，结果不具可比性

## 核心贡献点重新定位

### 选择的核心贡献点：基于LLM的后置过滤机制（Post-hoc Filter）

**研究问题：**
"现有RAG系统中，检索到的知识块往往包含大量噪声信息，严重影响生成质量。如何设计一个有效的后置过滤机制来提升RAG系统的答案准确性？"

**核心假设：**
基于LLM的二元判断后置过滤机制，在提升RAG下游任务准确率方面，比传统的重排序（Reranking）方法更有效。

**创新点描述：**
1. **有用性判断模块** - 引入基于LLM的智能判断模块，对检索结果进行二次筛选
2. **四步判断流程** - 设计了系统化的判断流程：问题意图分析→内容主题识别→意图匹配评估→最终裁决
3. **思维链优化** - 利用Qwen3的`enable_thinking`特性，在判断任务中关闭CoT以提升效率

### 次要贡献点：多路径异构检索框架

**支撑作用：**
多路径检索为后置过滤提供了丰富的候选知识，是验证过滤机制有效性的基础。

## 实验设计框架

### 主要对比基线
1. **基础RAG** - 简单的"向量检索 + LLM生成"流程
2. **传统混合检索** - BM25 + 单一向量检索的组合
3. **SOTA Reranker** - 基于Cross-Encoder的重排序模型
4. **无过滤的多路径检索** - 我们的检索方法但不进行有用性判断

### 消融研究设计
1. **完整系统** - 多路径检索 + 有用性判断
2. **去掉有用性判断** - 仅多路径检索
3. **去掉查询重写** - 使用原始问题
4. **单路径检索** - 仅密集向量检索

### 评测数据集
1. **QuAC** - 验证对话式问答能力，特别是查询重写的效果
2. **Natural Questions** - 验证通用问答能力和过滤机制的有效性

### 评测指标
1. **检索阶段** - Recall@k, MRR@k, NDCG@k
2. **端到端问答** - Exact Match (EM), F1 Score, ROUGE-L
3. **效率指标** - 响应时间、计算成本

## 论文重新定位策略

### 标题建议
"Post-hoc Filtering for Retrieval-Augmented Generation: A LLM-based Approach to Improve Answer Quality"

### 摘要重点
1. 明确指出RAG系统中噪声信息的问题
2. 提出基于LLM的后置过滤解决方案
3. 强调在公共数据集上的实验验证
4. 突出相比SOTA方法的性能提升

### 相关工作重点
1. RAG系统中的噪声问题
2. 现有的重排序和过滤方法
3. LLM在信息过滤中的应用

## 实验预期结果

基于我们的系统设计，预期实验结果：
1. **有用性判断的有效性** - 相比无过滤的方法，EM和F1分数提升10-15%
2. **相比SOTA Reranker的优势** - 在复杂问题上表现更好，特别是需要多方面知识的问题
3. **多路径检索的贡献** - 相比单路径检索，召回率提升20-30%
4. **查询重写的价值** - 在对话式问答数据集上，相比直接使用原始问题，性能提升5-10%
